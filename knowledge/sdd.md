# SDD: 연차휴가 계산 모듈 `leave.js`

> 근거: `source.md`만 사용했다. 요구사항은 `prd.md`의 FR 번호를 따른다. 원본에 없는 내용은 **미정**으로 표시했다.

## 1. 개요
회계연도 기준 연차의 발생·사용·미사용 수당을 계산하는 ES Module. 외부 패키지 없이 Node 22에서 동작한다. 공개 함수는 `getGrants`, `getBalance`, `requestLeave`, `yearEndPayout` 네 개다.

## 2. Key Entities

| 엔티티 | 설명 | 주요 속성 | 관계 |
|---|---|---|---|
| Employee | 직원 | hireDate, annualSalary, absences | Absence를 가진다, Grant를 받는다, Usage를 신청한다 |
| Absence | 소정근로일 부재 기간 | from, to, reason | reason이 출근 간주면 개근월·출근율을 깨지 않는다 |
| Grant | 연차 발생 | date, days | 종류: 월 단위(FR-1), 첫 연간(FR-2), 기준일 연간(FR-3/FR-4) |
| Usage | 연차 사용 | date, unit | 같은 회계연도의 Grant를 차감한다 |
| FiscalYear | 회계연도 | 1/1 ~ 12/31 | 잔여는 회계연도 단위, 연말에 Payout으로 정산 |
| Payout | 미사용 연차 수당 | remainingDays, paidDays, dailyWage, amount | FiscalYear 말 잔여에서 계산 |

## 4. 설계

### 4.1 공통 계산
- **소정근로일**: 월 ~ 금. 공휴일은 빼지 않는다.
- **결근일 집합**: 출근 간주가 아닌 Absence의 from ~ to(양 끝 포함) 중 소정근로일.
- **기준일**: 매년 1월 1일. 연간 연차는 이 날 한 번에 발생한다.
- **근속연수(기준일)**: 입사일부터 기준일까지 만으로 채운 햇수 (2023-03-01 입사 → 2025-01-01 기준 1년).
- **출근율(year)**: (year의 소정근로일 수 − year의 결근일 수) ÷ year의 소정근로일 수.

### 4.2 `getGrants(employee, asOf)`
asOf(당일 포함)까지의 Grant를 날짜 순으로 반환한다. days가 0이면 넣지 않는다.
1. **월 단위 (FR-1)**: k = 1 ~ 11에 대해 구간 [입사일 + (k−1)개월, 입사일 + k개월)에 결근이 없으면 `입사일 + k개월`에 1일.
2. **첫 연간 (FR-2)**: `입사일 + 12개월`이 속한 달의 다음 달 1일에 14일.
3. **기준일 연간 (FR-3, FR-4)**: 첫 연간 발생일보다 뒤인 매년 1월 1일마다
   - 그날 근속연수가 1년 미만이면 발생하지 않는다.
   - n = 근속연수(그날), 일수 = min(14 + (n − 1), 25)
   - 직전 회계연도 출근율 < 0.8이면 일수 = 직전 회계연도 달력 월 중 결근 없는 달 수. 정확히 80%이면 위 공식을 따른다.
   - 첫 연간 발생일이 1월 1일이면 그해 1월 1일에는 기준일 발생을 하지 않는다.
   - 첫 연간 발생(2단계)에는 출근율을 적용하지 않는다.

### 4.3 `getBalance(employee, usages, asOf)`
asOf가 속한 회계연도 안에서 (asOf까지의 Grant 합) − (asOf까지의 Usage 합). 전년도 잔여는 연말에 수당으로 정산되고 다음 해로 이월하지 않으므로 포함하지 않는다(FR-9). 차감은 먼저 발생한 Grant부터 한다(FR-8).

### 4.4 `requestLeave(employee, usages, request)`
- unit이 허용 단위가 아니면 `{ approved: false }` (FR-6)
- 신청 일수 > 신청일 시점 잔여이면 `{ approved: false }` (FR-7)
  - 신청일 시점 잔여 = getBalance(employee, usages, request.date) = 그해 1월 1일부터 신청일까지 발생 − 같은 기간 사용
- 그 외 `{ approved: true }`

### 4.5 `yearEndPayout(employee, usages, year)`
1. remainingDays = getBalance(employee, usages, `${year}-12-31`)
2. paidDays = remainingDays를 0.5 단위로 내림
3. dailyWage = floor(연봉 ÷ 12 ÷ 209 × 8)
4. amount = floor(dailyWage × paidDays)

0.5일 단위 내림은 수당 계산에만 적용한다. 발생·사용·잔여는 0.25일 단위 그대로 둔다.

## 5. 검증 항목

| 입력 | 기대 결과 | 근거 |
|---|---|---|
| 2025-03-01 입사, 결근 없음 | 2025-04-01, 2025-05-01, …에 각 1일 | FR-1 |
| 2025-03-01 입사 | 2026-04-01에 14일 | FR-2 |
| 2025-03-20 입사 | 2026-04-01에 14일 | FR-2 |
| 2025-03-01 입사 | 2027-01-01에 14일, 2028-01-01에 15일 | FR-3 |
| 근속 12년 이상 | 25일 | FR-3 |
| 연봉 50,000,000원, 잔여 2.75일 | paidDays 2.5, dailyWage 159,489, amount 398,722 | FR-10 |

## 6. 미정
- 지각·조퇴가 있는 달을 결근이 없는 달로 보는지 — 원본에 없음
- 연차를 사용한 날을 출근율 계산에서 출근으로 보는지 — 원본에 없음
- 입사일로부터 1개월에 해당하는 날짜가 없는 달 (29~31일 입사) — 원본에 없음
